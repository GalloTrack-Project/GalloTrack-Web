Where the verdict stands

Everything checkable from code is clean. All eight S2 findings and every code-checkable S3 now measure zero, and each is enforced by a CI gate rather than by discipline. The half that needs eyes is not done. Nobody has walked the app in light and dark, driven it by keyboard, listened to it with a screen reader, zoomed it, or tried it on a phone. Until that happens those checks read blank, and a blank check is not a pass.

Three S3 items are honestly partial: the shadow and padding scales, and how widely the shared Card / Badge / loading primitives are adopted. The primitives exist and are tested; many pages still hand-roll their own. One S4 item is open by decision because deleting an unused splash screen and re-wiring it are both defensible.

05 · Your pass

What to actually do

Seven passes. Each one lists literal steps — where to go, what to click, what to look at. Work top to bottom; they build on each other. Write the outcome in the box, and if something fails note the page and what looked wrong.

Rules of thumb: a pass is only a pass if you saw it with your own eyes. If you are unsure, mark it as a note rather than a pass — an uncertain check re-opens triage, which is the safe outcome.

PassStepsYour result
Light walk
C2 C5 C6 K4
  1. Make sure the theme is light (sun icon, top-right).
  2. Visit each page: Dashboard, Registry, Catalog, Lineage, My Profile, Settings, and one admin page.
  3. On each page, read the smallest grey text you can find — captions under numbers, table headings, helper text under fields.
  4. Check that every text box has a visible outline.
  5. Check the charts on the Dashboard are legible.
  6. If something looks faint, note the page and what it was.
Dark walk
C5 C6 K4
  1. Click the sun/moon button (top-right) to switch to dark.
  2. Repeat exactly what you did in the light walk, on the same pages.
  3. Pay extra attention to the doughnut chart — look for any slice that disappears into the background.
  4. Judge dark separately; the palette is deliberately deep in light and luminous in dark.
Keyboard only
K2 K4 K6 K7
  1. Put the mouse aside. Press Tab once on a fresh page load — a "Skip to main content" link should appear. Press Enter.
  2. Keep pressing Tab. Every control you reach must show a visible focus ring.
  3. Open a dialog (Tab to "Log Out" in the sidebar, press Enter).
  4. Inside the dialog, press Tab repeatedly — focus must never escape to the page behind.
  5. Press Escape to close. Now press Enter without clicking anything — the dialog should reopen, proving focus came back to the button.
Screen reader
F2 F10 K2 N2
  1. Turn on NVDA, VoiceOver or Narrator.
  2. Open a form (Register). Move through it — each field should announce its label, and any hint or error underneath it.
  3. Open the Log Out dialog. It should announce its title and description, not just "dialog".
  4. Open the heading list (NVDA: Insert+F7). Each page should show exactly one heading level 1.
  5. Trigger a message (save something). It should be announced without your focus moving.
Zoom 200%
T6
  1. Press Ctrl and + four times (browser zoom to ~200%).
  2. Open the two densest pages: an admin list and the Registry.
  3. Check nothing clips, overlaps, or forces you to scroll sideways to read a line.
Phone widths
N4 A3 K10
  1. Narrow the browser to about 360px wide (or use a real phone).
  2. Check the bottom navigation bar appears and matches the sidebar items.
  3. Try tapping the small ✕ buttons that remove a strain or a leg colour — you should hit them first try.
  4. Repeat at tablet width (~768px) and desktop (~1440px).
Reduce motion
L6
  1. Turn on "Reduce motion" in your operating system’s accessibility settings.
  2. Reload the app.
  3. Confirm the floating cards and entrance animations have stopped, and that nothing disappeared as a result.
06 · Rules

How the verdict is computed

The workbench applies these in order and stops at the first that matches. Nothing here is a judgement call.

#RuleCurrent state
1Any S1 open → Rejectno S1 exists
2Any check not done → Incompletethe seven passes are blank — this is the live rule
3Something failed and is not rated → Triagenot reached
4Any S2 open → Reject0 of 12 open
5Only S3/S4 open → Approve with fixeswhere it lands once rule 2 clears
6Nothing open → Approvenot yet

What to expect. Finish the seven passes and rule 2 clears. Rule 4 is already satisfied — no S2 is open and each is CI-enforced, so none can quietly come back. That lands the verdict at Approve with fixes under rule 5, because three S3 items are partial and one S4 is open by decision. Reaching a clean Approve means finishing the shadow and padding scales, adopting the shared surface and loading primitives across pages, and settling the dead components — all follow-up work, not defects in what shipped.
